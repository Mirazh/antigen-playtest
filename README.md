# «Антиген» — сборка для плейтеста

Здесь лежит только **артефакт сборки** прототипа: собранная страница игры и её ассеты. Исходники,
документация и канон живут в отдельном приватном репозитории и сюда не попадают.

Играть: **https://mirazh.github.io/antigen-playtest/**

Сборка обновляется вручную и только тогда, когда это нужно: все участники одной сессии плейтеста
обязаны играть одну и ту же версию, иначе их наблюдения не сводятся между собой.

## Что это

Tower defense, в котором популяция врагов эволюционирует между волнами против **вашей** расстановки.
Прототип фазы 0: пятнадцать волн, четыре башни, обучения и звука ещё нет.

## Параметры адреса

| Параметр | Что делает |
| --- | --- |
| `?seed=3A7F19C2` | задаёт сид забега восемью hex — один и тот же сид даёт один и тот же забег |

Без параметра сид выбирается случайно при загрузке и печатается в верхней полосе.
